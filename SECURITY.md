# Security policy

Please report vulnerabilities privately to **security@storeenv.app** with a description, steps to reproduce and the impact you expect. Don't open a public issue. You'll get an answer within 3 working days, and a fix or a plan within 30 days for confirmed issues. Credit is given on request once a fix ships.

Please don't test against other people's accounts or data, and don't run denial of service tests against storeenv.app.

In scope: the code in this repository (`@storeenv/core` and the `storeenv` CLI) and the hosted service at storeenv.app.
